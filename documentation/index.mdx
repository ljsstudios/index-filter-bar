Search & Filters Bar is the bar at the top of the Shopify admin's index pages (Products, Orders, Inventory), rebuilt for your embedded app. It's matched to the admin's look and behaviour element by element, so merchants get the bar they already know.

It's built for **Polaris 2.0 web components** (`polaris-2.0.js`, the `s-*` elements), not the older Polaris React library.

## How it fits in

The bar never fetches your data. It hands you a search, filters and a sort; your page sends them to your own API and draws the table:

```tsx
const bar = useIndexFilters({ fields, sortOptions, columns, views, onViewsChange });

const { data, isFetching } = useOrders(bar.query, bar.filters, bar.sort);

return (
  <>
    <IndexFilterBar {...bar.props} />
    <s-table loading={isFetching || bar.pending}>{/* … */}</s-table>
  </>
);
```
