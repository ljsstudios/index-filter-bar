## The search field

| Key | Does |
| --- | --- |
| Typing | Searches. Typing a field's name narrows the field list. |
| <kbd>↓</kbd> <kbd>↑</kbd> | Move through the open list. |
| <kbd>Enter</kbd> | Picks the highlighted row: a field, a value or a condition. |
| <kbd>←</kbd> <kbd>→</kbd> | Move through the text and onto chips. Left from a chip's values opens its condition. |
| <kbd>Backspace</kbd> | From just after a chip, the first press reaches it and the second removes it. On a chip, removes it. |
| <kbd>Delete</kbd> | Removes the chip just after the caret. |
| <kbd>Escape</kbd> | Closes the list. The chip stays. |
| <kbd>Tab</kbd> | Leaves the field. |

Typing straight after a list chip narrows its values. Typed values work like this:
- **Numbers:** <kbd>Enter</kbd> applies them, and <kbd>Tab</kbd> moves from a range's first number to its second.
- **Dates:** each part moves to the next when it's full.

## Views menu

| Key | Does |
| --- | --- |
| <kbd>↓</kbd> <kbd>↑</kbd> <kbd>Home</kbd> <kbd>End</kbd> | Move through the views. Opening the menu focuses the current view. |
| <kbd>→</kbd> on "…" | Opens the view's actions; <kbd>←</kbd> goes back. |
| <kbd>Escape</kbd> | Closes the menu. |

## Save

| Key | Does |
| --- | --- |
| <kbd>⌘</kbd> <kbd>S</kbd> | Update view; on All, Save as new view. |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>S</kbd> | Save as new view. |

<kbd>Ctrl</kbd> on Windows and Linux. These work while Reset and Save are showing.

## Columns menu

| Key | Does |
| --- | --- |
| <kbd>Space</kbd> on a reorder handle | Picks the column up. |
| <kbd>↓</kbd> <kbd>↑</kbd> | Move it. |
| <kbd>Space</kbd> | Drops it. |
| <kbd>Escape</kbd> | Cancels the move; a second <kbd>Escape</kbd> closes the menu. |
