# Changelog

## 0.1.0 (2026-11-08)

The first release.

- **Filters:** every filter type the admin has: list, number, date, text, currency, measurement and read-only.
- **Saved views,** with Reset, Save, Update, Save as new and the "Show view filters" eye.
- **Columns and sort:** reorder, hide and sort columns, or a sort button of its own.
- **Choosing the parts:** saved views, sort, columns and filters are each optional.
- **The URL:** search, filters, sort and view in readable params.
- **Long lists,** paged locally or from a server.
- **Languages:** English, German, Spanish and French.
- **Accessibility:** checked with axe against WCAG 2.2 AA.
